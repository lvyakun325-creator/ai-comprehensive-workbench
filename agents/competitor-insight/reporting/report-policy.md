# 竞品洞察证据型报告政策

## 固定章节

报告按以下顺序输出：证据范围与完整性、核心发现、内容机会、拍法模板、转化与承接、7 天执行清单、待验证假设、合规审查。结论必须可追溯到已提供的证据，不以缺失数据补写事实。

## 首期输入与结构化输出协议

首期唯一输入源是用户提供的**单个抖音账号 Excel** 证据文件及其确定性解析结果；不混入小红书、其他账号、网页抓取或模型自行补充的数据。模型只输出符合 `section-batch.schema.json` 的 JSON 对象，不输出 Markdown、代码块、说明文字或其他字段。

证据数字（点赞、评论、收藏、分享、总互动、发布时间、行号及各榜单名次）只由确定性证据层读取和计算。模型只能引用既有 `evidenceId`，不得输出、计算、改写或推断这些证据数字；报告渲染如需展示数字，只能从已验证的 `EvidenceBundle` 读取。

## 证据与判断口径

每条内容证据使用 `evidenceId`、`sourceRow`、标题、发布时间、链接、点赞、评论、收藏、分享、总互动及各榜单名次。所有发现、选题、拍法、转化动作和每日执行项均须列明至少一个 `evidenceId`。

`direct` 仅用于可由数据或作品原文直接支持的陈述；`weak` 用于证据有限但存在合理信号的判断；`hypothesis` 用于尚未被证实的推测。`weak` 与 `hypothesis` 必须说明依据和验证方式，不得表述为既成事实。

## 固定产出

- 选题方向：输出 5 个，每项含题目、内容角度、证据和合规提示。
- 拍法模板：输出 3 个，每项含名称、开场钩子、结构、证据和合规提示。
- 7 天清单：逐日输出第 1 至 7 天的动作、证据和合规提示。
- 转化与承接：只给可合规执行的内容承接、健康档案、用药提醒、复诊提醒或营养记录等动作，并标注证据和合规提示。

## 医药健康合规边界

不作疾病诊断，不替代医生建议，不承诺疗效；不用“根治、治愈、保证有效、无副作用、最安全、唯一方案”等绝对化表述；不引导停药、换药、加量或减量；不把普通食品、保健品或器械包装为药品疗效；不编造医生、医院、病例或数据，不制造焦虑。

涉及处方药、互联网医院或慢病管理时，报告必须提示资质、审方、处方、合规承接与平台规则风险。对视频号、小红书、直播、详情页、主图、标题和评论区，优先采用生活方式、认知提醒和日常管理表达，不以问诊互动或夸大医疗营销引导转化。
