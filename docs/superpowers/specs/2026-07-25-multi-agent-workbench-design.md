# AI 综合工作台：总控台与九个独立 Agent 项目设计

日期：2026-07-25  
状态：待用户书面确认  
本阶段边界：完成产品与 UI 规格，不连接模型、不创建真实 Agent、不运行任务、不发布上线。

## 1. 目标

将现有 AI 综合工作台升级为一个多 Agent 项目系统：

- 保留首页 AI 对话入口。
- 建立一个只负责拆解、调度和汇总的总控台。
- 建立九个一对一对应业务功能的独立 Agent 项目。
- 保证每个 Agent 只能操作自己的项目、资料、任务和成果。
- 通过明确的“成果交接”机制连接上下游，不允许跨项目直接修改。
- 最终每个 Agent 项目都能够独立实现对应业务能力。

## 2. 产品结构

### 2.1 总控台

总控台只负责：

1. 接收用户经营目标。
2. 将目标拆分为独立任务。
3. 判断任务依赖和执行顺序。
4. 将任务分配给指定 Agent。
5. 查看各 Agent 的执行状态。
6. 汇总各 Agent 已确认的成果。
7. 控制暂停、重试、终止和人工确认。

总控台不直接生产标题、文章、口播、视频或复盘报告，避免与专业 Agent 职责重叠。

### 2.2 九个独立 Agent 项目

| 编号 | Agent 项目 | 职责边界 | 标准输入 | 标准输出 |
|---|---|---|---|---|
| 01 | 内容矩阵 Agent | 账号定位、栏目结构、平台分工、更新节奏 | 业务目标、产品、平台、人群 | 内容矩阵方案 |
| 02 | 竞品洞察 Agent | 竞品采集、内容拆解、差异判断、机会识别 | 竞品链接、截图、数据、分析要求 | 竞品洞察报告 |
| 03 | 选题策划 Agent | 人群场景、需求问题、选题池、排期建议 | 内容矩阵、竞品洞察、产品资料 | 选题清单 |
| 04 | 标题策划 Agent | 标题方向、搜索词、点击表达、风险检查 | 选题、平台、目标人群 | 标题方案 |
| 05 | 新媒体图文 Agent | 正文、结构、配图规划、多平台改写 | 选题、标题、品牌资料 | 图文内容包 |
| 06 | 超级 AI 写作 Agent | 长文、私域、品牌稿、知识库驱动写作 | 写作任务、品牌资料、历史稿件 | 完整稿件 |
| 07 | 爆款口播 Agent | 爆款结构拆解、传播钩子、自然口播生成 | 对标内容、主题、产品资料 | 口播脚本包 |
| 08 | 获客视频 Agent | 分镜、配音、画面、字幕、成片流程 | 口播脚本、素材、品牌规范 | 视频生产包 |
| 09 | 数据复盘 Agent | 流量、转化、内容产能、复购与行动诊断 | 平台数据、投放数据、内容结果 | 复盘报告与行动清单 |

## 3. 项目隔离规则

每个 Agent 项目拥有独立的：

- 项目标识与工作空间。
- 对话记录。
- 项目资料。
- Agent 提示词与业务规则。
- 模型与参数配置。
- 任务队列。
- 中间过程文件。
- 最终成果文件。
- 调用次数、成本和执行日志。

默认禁止：

- 直接读取其他 Agent 的私有资料。
- 直接修改其他 Agent 的任务、配置或成果。
- 多个 Agent 同时写入同一成果文件。
- 未经用户确认将医药、客户或经营敏感资料发送给新的模型服务商。

## 4. 共享资产与成果交接

### 4.1 公共资产库

公共资产库用于存放所有 Agent 可以读取的稳定资料：

- 企业与品牌主档。
- 产品基础资料。
- 平台规范。
- 医疗健康合规规则。
- 品牌语气与视觉规范。
- 已确认的通用模板。

Agent 对公共资产库默认只读。新增、覆盖或删除公共资产必须由总控台发起并经过用户确认。

### 4.2 成果交接

跨 Agent 协作只通过成果交接单完成。交接单至少包含：

- 来源 Agent。
- 目标 Agent。
- 来源项目与成果版本。
- 交接目的。
- 可使用范围。
- 是否允许复制到目标项目。
- 用户确认状态。

交接后，目标 Agent 获得的是成果副本或只读引用，不获得来源 Agent 的完整项目权限。

## 5. 页面信息架构

左侧主导航：

1. 总控台
2. Agent 项目
3. 任务中心
4. 成果资产库
5. 数据概览
6. 模型配置
7. 系统设置

### 5.1 总控台首页

保留当前首页 AI 沟通界面，角色更名为“总控 Agent”。

首屏包含：

- 当前问候与经营目标输入框。
- 模型选择。
- 附件与工具入口。
- “拆解并分配”主按钮。
- 当前可用并发数。
- 今日任务、待确认成果、异常任务摘要。

首屏下方展示九个 Agent 项目卡片。每张卡片显示：

- Agent 名称和职责。
- 隔离状态。
- 当前模型。
- 运行中、排队中、待确认任务数量。
- 最近成果。
- 进入项目按钮。

### 5.2 Agent 项目列表

提供三种视图：

- 卡片视图：适合快速进入。
- 运行视图：只展示运行中和排队中的项目。
- 依赖视图：展示成果交接和上下游关系。

### 5.3 单个 Agent 项目页

所有 Agent 项目采用统一外壳，业务表单和成果区按 Agent 职责变化。

页面顶部固定展示隔离提示：

> 当前位于「竞品洞察 Agent」。它只会操作本项目资料，不会修改其他 Agent 项目。

统一模块：

1. 项目总览
2. Agent 对话
3. 任务列表
4. 项目资料
5. 执行过程
6. 成果文件
7. 成果交接
8. Agent 配置

### 5.4 任务中心

任务中心展示：

- 运行中
- 排队中
- 待人工确认
- 已完成
- 失败
- 已暂停

每个任务显示：

- 所属 Agent。
- 所属项目。
- 当前步骤。
- 上游依赖。
- 使用模型。
- 已用时间与调用量。
- 暂停、重试、终止按钮。

当前 Codex 环境按一个主 Agent 加三个子 Agent 的并发上限设计。超过并发数的任务进入队列，不丢弃、不抢占其他项目。

### 5.5 成果资产库

成果分为：

- 私有成果：仅所属 Agent 项目可见。
- 待交接成果：等待用户确认交付范围。
- 已共享成果：按交接单授权给指定 Agent。
- 公共模板：所有 Agent 只读。

所有成果必须保留版本、来源和生成记录。

### 5.6 模型配置

模型配置分两层：

- 全局可用模型：由总控台维护可用服务商。
- Agent 默认模型：每个 Agent 独立选择，不影响其他 Agent。

API 密钥只在后续接口阶段通过服务端安全保存，前端不显示完整密钥，不写入日志或项目成果。

## 6. 核心交互

### 6.1 从总控台发起

1. 用户输入目标。
2. 总控 Agent 生成任务拆解预览。
3. 用户确认任务、Agent、顺序和预算。
4. 独立任务最多三个并行执行。
5. 有依赖的任务等待上游成果确认。
6. 总控台汇总最终成果，不修改专业 Agent 的原始成果。

### 6.2 从单个 Agent 发起

1. 用户进入指定 Agent。
2. 新建或选择该 Agent 下的项目。
3. Agent 只读取本项目资料和已授权的公共资产。
4. 执行结果只写入当前项目。
5. 需要传给其他 Agent 时创建成果交接单。

### 6.3 异常处理

- 单个 Agent 失败只影响自己的任务。
- 失败任务保留输入、中间状态和错误摘要。
- 重试默认创建新执行版本，不覆盖上一版本。
- 上游失败时，下游进入“等待依赖”，不自动使用不完整成果。
- 成本超过用户设定上限时自动暂停并请求确认。

## 7. 医药电商与数据安全

- 医疗健康内容在输出区显示合规状态。
- 涉及诊断、疗效承诺、停换药、绝对化表达时标记风险。
- 发布前保留人工确认节点。
- 客户隐私、处方、身份证件、手机号和账户凭据不得进入模型日志。
- 竞品采集、平台登录态和 Cookie 不自动共享给任何 Agent。
- 不同模型服务商的数据发送范围必须可见、可控制、可审计。

## 8. UI 视觉口径

- 延续当前浅色经营工作台风格。
- 总控台使用深蓝主色，代表调度和全局视角。
- 九个 Agent 保留各自识别色，但使用统一卡片结构。
- 所有项目页固定显示 Agent 名称、项目名称和隔离边界。
- 状态使用统一颜色：运行中为蓝色、待确认为橙色、完成为绿色、失败为红色、暂停为灰色。
- 桌面端以三列 Agent 卡片为主，移动端改为单列。

## 9. 实现阶段拆分

后续实现必须分项目推进，每次只修改当前 Agent 对应的目录和共享接口。

建议顺序：

1. 总控台与统一 Agent 外壳。
2. 项目隔离、任务状态和成果交接基础。
3. 内容矩阵 Agent。
4. 竞品洞察 Agent。
5. 选题策划 Agent。
6. 标题策划 Agent。
7. 新媒体图文 Agent。
8. 超级 AI 写作 Agent。
9. 爆款口播 Agent。
10. 获客视频 Agent。
11. 数据复盘 Agent。
12. 模型接口、权限、安全和全链路验证。

在某个 Agent 项目开发期间：

- 只修改该 Agent 目录。
- 共享接口需要变更时单独提交。
- 不顺带重构其他 Agent。
- 必须运行该 Agent 的独立测试和工作台全局回归测试。

## 10. 本阶段验收标准

本设计确认后，下一阶段先实现 UI 外壳，不运行真实 Agent。UI 外壳应满足：

- 能从总控台进入九个独立 Agent 项目。
- 每个项目页明确展示职责和隔离提示。
- 能查看模拟任务状态、成果和交接界面。
- 能查看独立模型配置入口。
- 所有按钮在未接入功能时明确提示“设计预览”，不产生真实外部操作。
- 不改变或删除现有九个功能定义。
