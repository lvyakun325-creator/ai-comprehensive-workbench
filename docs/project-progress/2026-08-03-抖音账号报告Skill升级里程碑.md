## 本次目标

## 已完成

- 新增独立 `report_generator.py`，没有把大段报告逻辑塞入 `main.py`。
- 支持直接读取已有账号 `.xlsx`，识别账号概览、全部作品及常见同义字段。
- 支持 `w`、`万`、`亿`、逗号、空值和数字单元格。
- 按现有点赞、评论、收藏、分享字段计算综合互动量。
- 输出账号基础信息、数据总览、Top 10、起号期 Top 5、内容方向、爆款共性、证据型对标建议和 7 天清单。
- 缺字段、无作品、作品不足 10/5 条、缺发布时间时明确披露，不补造数据。
- 新抓取并启用 `--report` 时使用内存中的原始结构化数字，避免 Excel 展示值四舍五入影响排序。
- 医疗健康标题自动加入合规提醒：不诊断、不承诺疗效、不引导停换药或调整剂量。
- 更新 `SKILL.md` 和 `agents/openai.yaml`，明确只抓取、抓取并分析、已有 Excel 三种路由。
- 同步安装版与原 standalone 安装包的报告生成器、入口、说明和离线测试。
- 将当前已验证的 `bridge_server.py` 及桥接合同测试补入 standalone，避免重装时删除网页工作台所需的抖音采集桥。

## 新增命令

### 已有 Excel 直接生成报告

```bash
~/.codex/skills/douyin-scraper/.venv/bin/python \
~/.codex/skills/douyin-scraper/report_generator.py "<账号数据.xlsx>"
```

### 抓取账号并生成报告

```bash
~/.codex/skills/douyin-scraper/.venv/bin/python \
~/.codex/skills/douyin-scraper/main.py "<抖音账号链接或标识>" --report
```

### 只抓取 Excel

```bash
~/.codex/skills/douyin-scraper/.venv/bin/python \
~/.codex/skills/douyin-scraper/main.py "<抖音账号链接或标识>"
```

## 风险与边界

- 已有旧 Excel 如果只保存了 `1.5w` 这类展示值，脚本只能按展示值还原；新抓取报告使用原始结构化数字，不受此限制。
- Excel 没有视频正文、画面、评论正文、商品、直播、私域或资质信息时，报告不会给出确定结论。
- 当前脚本生成的是确定性证据型报告，不在 Skill 内保存或调用任何模型 API Key；Agent 可润色解释文字，但不得修改数字、排名和证据引用。
