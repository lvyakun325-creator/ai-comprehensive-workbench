# 2026-08-03 竞品洞察独立模型配置里程碑

## 结论

竞品洞察 Agent 已改为完全独立的模型配置，并正式发布到 Sites V16。竞品报告不再读取或回退到全局模型。

## 已完成

- 在「竞品洞察 Agent → Agent 配置」新增独立模型配置页面。
- 支持 OpenAI 与 APINebula 预设，可单独填写 API 地址、模型名称和 API Key。
- 连接测试成功后才能应用到竞品洞察，修改草稿不会影响正在使用的配置。
- 竞品报告运行器改为只读取竞品会话级配置，移除全局模型注册表依赖。
- 即使全局模型已连接，竞品未配置独立模型时仍停在证据就绪阶段，不会发起模型请求。
- 独立模型或凭据变化时中止旧请求，避免旧响应写入新任务。
- API Key 只存在当前页面内存，刷新即清空，不写入本地存储、项目文件或日志。
